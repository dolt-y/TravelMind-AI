## 行程导出 PDF

- 新增 `app/services/plan_export.py`：用 ReportLab 把 `TripPlan` 渲染成多页 A4 文档（封面信息、费用估算、行程提醒、逐日安排、行前建议）。
- 新增接口 `GET /api/trip/plan/{plan_id}/export.pdf?language=zh|en|ja`，返回 `application/pdf` 附件，`Content-Disposition` 同时给出 ASCII 名与 RFC 5987 的 `filename*`。
- 字体策略：优先内嵌系统 TrueType（macOS STHeiti Light/Medium、Linux wqy-zenhei 等），可用 `TRAVELMIND_PDF_FONT` / `TRAVELMIND_PDF_FONT_BOLD` 覆盖；都没有时退回 ReportLab 内置 CID 字体（STSong-Light / HeiseiKakuGo-W5）。注意 ReportLab 不能内嵌 CFF/OTF 轮廓（PingFang、Noto CJK 会失败）。
- 前端：`services/travel.ts` 增加 `exportTripPlanPdf`（blob 下载 + 解析 filename），`ResultsView` banner 增加「导出 PDF」按钮（loading / 失败提示），i18n 补 zh/en/ja 文案。
- 测试：新增 `tests/test_plan_export.py`（渲染三语言 + 空行程 + 未知语言回退 + 接口 200/404/422）。后端 57 个测试全过，前端 lint 与 build 通过。
- 依赖：`pyproject.toml` / `uv.lock` 增加 `reportlab`。

### 补充：景点图片进 PDF

- 新增 `app/services/image_fetcher.py`：`fetch_attraction_image(url)` 流式下载（5s 超时、4MB 上限、content-type 白名单、`trust_env=False`），用 Pillow `ImageOps.fit` 中心裁剪成 480×360 JPEG（q82），`lru_cache(128)` 缓存在进程内。
- `plan_export` 并发抓取各景点首图（ThreadPoolExecutor 6 线程、最多 16 张），渲染到景点卡片右侧 40×30mm；任一图失败只影响该卡片，降级为纯文字。
- 关键坑：ReportLab 对 JPEG 走 `DCTDecode` 直嵌，但如果 `image_provider` 直接返回原图字节会绕过缩略图处理，一份 PDF 能涨到 2.8MB。provider 的契约是「返回可直接嵌入的成品图片字节」。
- 接口增加 `images` 查询参数（默认 true，`images=false` 跳过下载）；前端导出单独把超时放宽到 90s。
- 测试扩到 11 个（缩略图裁剪/坏数据、图片内嵌断言 `/Subtype /Image`、缺图降级、images=false）。后端 62 个测试全过。
